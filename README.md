# ECOMMERCE WEBSITE

A full-stack e-commerce website built using React frontend and Flask backend.

## Features

- User Registration and Login
- Product Browsing
- Product Search
- Shopping Cart
- Wishlist
- Checkout
- Online Payments
- Orders and Order Tracking
- Product Reviews
- Coupons
- Notifications
- Admin Dashboard
- Product Management
- User Management
- Order Management
- Review Management

## Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Python
- Flask
- Flask REST API

### Database
- SQL Database
